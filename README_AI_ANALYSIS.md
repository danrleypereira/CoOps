# AI Analysis (Gemini)

This module generates JSON files with AI-powered analyses (Gemini) for the organization's members using data already extracted in the bronze layer (commits, issues, and pull requests).

## Output

- `data/silver/ai/members_ai.json`

Each file contains:
- `_metadata` with org, scope, model info
- `members`: object keyed by member login with commit, PR, and issue analyses

## Prerequisites

1. Python 3.10+
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Set the Gemini API key as an environment variable (or via `.secrets` in the project root):

```bash
export GEMINI_API_KEY="<YOUR_KEY>"
# or
export GOOGLE_API_KEY="<YOUR_KEY>"
```

Or create/edit a `.secrets` file in the repository root:

```
GEMINI_API_KEY=<YOUR_KEY>
```

## Usage

```bash
# Generate AI analysis for all members
python -m src.ai_analysis.generate_members_ai

# Test mode (processes only 3 members)
python -m src.ai_analysis.generate_members_ai --test
```

- The process respects rate limits (QPS and concurrency) with retry and backoff logic.
- Re-runs will regenerate the full analysis.

## Notes

- Bronze layer inputs must follow the pattern generated by this repository's pipeline (`commits_*.json`, `issues_*.json`, `prs_*.json`).
- The AI analysis degrades gracefully: if `GEMINI_API_KEY` is not set, the gold-process workflow skips the AI step entirely.
- To reduce cost/time, use `--test` mode to process only a sample of members.

## CI/CD Integration

The AI analysis is integrated into the `gold-process.yaml` workflow:
1. After gold layer processing completes, the workflow checks if `GEMINI_API_KEY` is configured
2. If enabled, it runs the AI analysis and commits results to `data/silver/ai/`
3. If disabled, a notice is logged with setup instructions
